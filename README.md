# حساباتي

تطبيق Android مبني باستخدام Flutter + Dart لإدارة حسابات العملاء والعمليات (له/عليه) محلياً دون الحاجة للإنترنت.

## المزايا
- إضافة وتعديل وحذف العملاء.
- بيانات العميل: الاسم، الهاتف، العنوان، الملاحظة.
- إضافة عملية على حساب العميل: **له** أو **عليه**.
- المبلغ والعملة والبيان والتاريخ.
- العملات: الريال اليمني YER افتراضياً، الريال السعودي SAR، الدولار USD.
- عرض الرصيد لكل عميل وإجمالي الحسابات.
- بحث عن العملاء.
- مشاركة تفاصيل العملية كنص عبر تطبيقات المشاركة مثل واتساب وSMS.
- تقارير مختصرة حسب العملاء.
- واجهة عربية RTL.
- قاعدة بيانات SQLite محلية.

## البناء
بعد رفع المشروع إلى GitHub:
1. افتح تبويب Actions.
2. شغّل workflow باسم `Build Android APK`.
3. بعد اكتمال البناء حمّل artifact باسم `حساباتي-apk`.

أو محلياً باستخدام Flutter:
```bash
flutter pub get
flutter build apk --release
```
وسيكون الملف في:
`build/app/outputs/flutter-apk/app-release.apk`
